# Northbound — Trip Report

A polished, responsive trip-report website for an HTML/CSS/JavaScript academic project, featuring an editorial field journal and a traditional structured report.

## What is included

- Editorial-style responsive layout
- Smooth scrolling and scroll-reveal animation
- Mobile navigation
- Traditional report with purpose, itinerary, observations, estimated expenses, and recommendations
- Interactive destination field notes
- Journal category filters
- Photo gallery + lightbox
- Live PHP trip-budget calculator
- Interactive packing checklist with feedback
- Accessible keyboard Escape handling for overlays
- Mobile, tablet and desktop layouts
- No framework or build process required

## Run locally

Because this is a static site, no server or installation is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Keep `style.css` and `script.js` in the same folder.

## Publish for classmates / professor

The simplest option is GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub will provide a public Pages address after deployment.

The website is intentionally static, so visitors do not need VS Code, Node.js, XAMPP, or any other software. They only need the published URL and a modern browser.

## Report sections

The website is organized around four clearly identified parts of a trip report:\n\n1. **Before the trip** — purpose, objectives, preparation, itinerary, arrangements and budget.\n2. **During the trip** — destinations, daily activities, observations, experiences and field notes.\n3. **After the trip** — photographs, organized journal entries, expense review and reflection.\n4. **Suggestions and conclusion** — practical recommendations for future trips and the overall findings.\n\nA four-card report guide appears near the beginning of the website, and the main navigation links directly to each part. The editorial journal, traditional report, gallery, budget calculator and packing checklist support these four sections. The report content and budget can be edited directly in `index.html`.


## Field trip report learning guide

The website also includes a guide aligned with the field trip report reference: a definition, the five main report components, key observation prompts (people, places, activities, significance, and personal reflection), key takeaways, benefits of report writing, and a short example. The existing Northbound travel journal and full traditional report remain available as they were.
